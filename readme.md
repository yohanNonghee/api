### Infinite Scroll Gallery ###
A modern, responsive web application that fetches stunning random photos from the Unsplash API and displays them in a sleek grid layout. It features an Infinite Scroll mechanism that automatically loads more images as the user scrolls down the page.

#  Project Description & Details
Infinite Scroll Gallery is designed to provide a seamless and engaging visual browsing experience. Instead of relying on traditional pagination, the application dynamically loads new batches of high-resolution images in the background as the user approaches the bottom of the page.

# Key Features:
- Dynamic Infinite Scrolling: Automatically detects user scroll position and fetches new images without requiring page reloads.
- Responsive Grid Layout: Built with CSS Grid and Flexbox, ensuring a clean and adaptive presentation across various screen sizes (from mobile devices to large desktops).
- Loading State Management: Implements an animated loading spinner and an image-loading check mechanism to ensure smooth rendering before revealing content.
- Modern Dark Theme UI: Styled with a polished dark-mode color palette, custom gradients, smooth hover transitions, and Google Fonts (Plus Jakarta Sans).
- Direct Attribution: Each image links directly to its original page on Unsplash, respecting creator attribution and licensing.

# APIs Used
Unsplash API:
- Endpoint: [https://api.unsplash.com/photos/random], (https://api.unsplash.com/photos/random)
- Purpose: Used to fetch a randomized set of high-quality images per request, controlled by query parameters such as client_id (for authentication) and count (to specify the number of images retrieved per batch).

# Currency Converter
A lightweight, user-friendly web application built with vanilla JavaScript that allows users to convert values between multiple global currencies in real-time using live exchange rates.

# Project Description & Details
Currency Converter provides a clean and intuitive interface for quick currency conversions. Users can select two different currencies, input an amount, and instantly see the calculated equivalent based on up-to-date market rates. It also features a quick-swap function to reverse the conversion direction effortlessly.

# Key Features:
- Real-Time Conversion: Automatically calculates and updates the converted amount as the user types or changes currency options.
- Currency Swapping: Includes a convenient swap button to instantly switch and invert the primary and secondary currencies.
- Live Exchange Rates: Displays clear and precise exchange rate ratios for the selected currency pair.
- Comprehensive Currency Support: Supports a wide variety of global currencies via selection dropdown menus.
- Modern Minimalist UI: Styled with a clean card layout, smooth transitions, and Google Fonts (Roboto) for a polished user experience.


# APIs Used
ExchangeRate-API:
- Endpoint: [https://api.exchangerate-api.com/v4/latest/], (https://api.exchangerate-api.com/v4/latest/){currency}
- Purpose: Used to fetch the latest available foreign exchange rates relative to a selected base currency dynamically.



# Technologies Used
- HTML5 & CSS3 (Variables, Flexbox, CSS Grid, Custom Animations,Custom UI Elements, Box Shadows)
- TypeScript
- JavaScript (ES6+) (Async/Await, Fetch API, DOM Manipulation, Event Listeners,DOM Event Handling, Error Handling)
